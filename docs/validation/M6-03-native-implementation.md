## Native authority and resource ownership

The addon captures a canonical directory descriptor, device/inode and alias/canonical metadata paths. Initial aliases resolve via metadata; canonical acquisition uses all-component `O_NOFOLLOW_ANY`. All relative file/directory acquisition uses `openat` on the held root with `O_NOFOLLOW_ANY | O_NONBLOCK | O_CLOEXEC`; absolute, NUL, backslash, empty, dot, parent and empty-component relative inputs reject first. Nonblocking acquisition prevents FIFO open from blocking before regular-file validation.

Native resources are opaque type-tagged objects, never numeric descriptors. Wrong/forged/prototype-cloned resources reject. Closed objects retain closed state, and cannot acquire authority from a reused descriptor number. Deterministic `close` is idempotent, cancels/join-retires active work, then closes once. Each active job retains its resource and job object through Node-API references. Resource finalizers close abandoned handles; escaped cancellation functions separately retain their native job allocation until both wrappers finalize. File/directory objects allow one operation at a time; roots allow concurrent opens/verifications.

Node-API async execute/complete owns real filesystem work. Reads are at most 64 KiB; listings at most 128 entries; cancellation is checked before work and within listing/read-interruption loops. Short reads, EINTR, file/directory metadata mutation and nonregular/symlink entries have explicit outcomes. No special entries are silently treated as absent. Each directory open obtains a fresh stream/offset; streams close their owned descriptor. Core copies accumulated file chunks in yielding bounded steps, rather than one unbounded synchronous copy loop.

`verify` uses only metadata (`stat` alias and canonical path compared with captured inode/device); it never reopens content by pathname. Retargeting may fail verification while held reads/listings continue to return only original owned bytes/names. This is held-directory-object authority, not an atomic project snapshot or provenance guarantee for ordinary files moved into an authorized directory. Metadata checks cannot turn concurrent ordinary writes into an atomic snapshot.
