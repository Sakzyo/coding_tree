## Saved identity, immutability and currency

Root/file read authority must hold at actual capture and execution boundaries under replacement or symlink changes; lexical containment or a historical authorization call is insufficient.

A recommended saved-source identity is a versioned canonical SHA-256 manifest of sorted project-relative input paths and exact-byte digests, with unambiguous encoding and separate canonical-root binding. Addition/deletion/rename counts. A digest does not prove completeness or atomic capture; the trusted lease must establish both. Avoid buffer text, secrets in public output, Git HEAD, timestamps, file sizes, open-file-only hashes or summed diskRevision counters as the source basis.

Consumed configuration bytes also belong in the source manifest.

The process consumes that retained snapshot, while the lease reports live source/configuration changes until settlement. If snapshot execution relocates the wrapper, the trusted recipe binds its clone to the exact captured project wrapper bytes/properties and canonical descriptor provenance; it does not silently select global Gradle. The alternative live-project recipe is acceptable only with authoritative complete change-aware interval guarantees plus identities. `BuildRun` is a Core-only runtime handle `{ buildID, result: Effect<BuildEvidence>, cancel: Effect<BuildEvidence> }`. `BuildQuery` is `{ projectID, buildID }`; `BuildRecord` is a closed running/settled union, with evidence only when settled. IDs are lookup identities, never bearer authorization.

The convenience build path brackets admission/handle adoption so interruption between start and await cannot lose cancellation ownership. Keep lengthy acquisition/start I/O interruptible; mask only admission/terminal bookkeeping. Interruption before admission closes any acquired resources and yields no record; after admission, the owned worker/finalizer always settles once. `result` awaits the owner Deferred. Cancelling this wait alone does not abandon the owner; explicit handle cancellation joins the child and returns its stored terminal evidence. `build` is the planned convenience path: obtain a run, await its result, and on caller interruption cancel/join the admitted run under cleanup masking, then preserve caller interruption. An independent holder of the issued ID/handle queries the settled cancelled evidence; no cancelled return is promised to that interrupted fiber.

Linearize terminal publication and cancellation: cancel before publication wins cancelled; cancel after publication returns unchanged existing terminal evidence. Repeated cancel/result/read calls reuse one immutable result. Owner disposal closes admission, cancels/joins every active build and releases leases/output resources before clearing owner-local records.
